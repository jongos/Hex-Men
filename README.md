# Hex Men

**Six Tools for Better Products and Clearer Communication.**

Hex Men is a suite of design and UI/UX skills and tools for AI agents, created by Jon Gosier. Create interfaces, check design decisions, test user journeys, rehearse workflows, simplify products and sharpen marketing copy and AI outputs.

## Choose Your Question

| You Want To… | Start With | What You Get |
|---|---|---|
| Give an idea a visual voice | [Dazzler](https://github.com/jongos/Dazzler) | Interfaces, documents and slides shaped around your brief |
| Check whether the experience holds up | [Longshot](https://github.com/jongos/Longshot) | Reproducible findings and acceptance tests |
| Explain and check a design decision | [Style Science](https://github.com/jongos/style-science) | Measurable checks linked to design requirements |
| Find handoff gaps before building | [Spiral](https://github.com/jongos/Spiral) | Handoff gaps, ownership and recovery requirements |
| Remove complexity without losing the job | [Shatterstar](https://github.com/jongos/Shatterstar) | Simplification proposals with task checks and rollback plans |
| Make AI outputs clear and direct | [Mojo](https://github.com/jongos/Mojo) | Less repetition, needless nuance and overly cautious language |

## See How They Connect

Imagine an approval service. **Spiral** asks whether the requester learns that approval is complete. **Dazzler** shapes the interface. **Style Science** makes its requirements inspectable. **Longshot** tries the rendered task and checks the outcome. **Shatterstar** considers whether duplicate status views can be combined without losing retrieval or recovery. **Mojo** makes the copy and agent updates clear and direct.

Choose the tool that fits your task, or use findings from one to guide another.

## Get Started

Open a project’s repository for setup and examples. Dazzler, Longshot, Spiral, Shatterstar and Mojo are agent skills. Style Science provides JavaScript and Python tools.

To use Mojo after installation: `Use $mojo-language to cut repetition, needless nuance and overly cautious language from this output.`
